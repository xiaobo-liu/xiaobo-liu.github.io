<font size="5">Non-simulative implementation</font>

<ul>

<li> <b>phi_funm</b><br>
Computing matrix \(\varphi\)-functions arising in exponential integrators.    
<a href="https://github.com/xiaobo-liu/phi_funm">Source code</a>.</li>

<li> <b>matrices-expm</b><br>
Collection of MATLAB functions that generate test matrices from the literature for computing the matrix exponential. 
<a href="https://github.com/xiaobo-liu/matrices-expm">Source code</a>.</li>

<li> <b>matrices-mp-cosm</b><br>
Collection of MATLAB functions that generate test matrices from the literature for computing the matrix cosine. 
<a href="https://github.com/xiaobo-liu/matrices-mp-cosm">Source code</a>.</li>

<li> <b>sqrtm-lrpsi</b><br>
Algorithms for computing the square root of low-rank-perturbed scaled identity matrix. 
<a href="https://github.com/xiaobo-liu/sqrtm-lrpsi">Source code</a>.</li>

</ul>

<font size="5">Simulation of multiprecision/mixed-precision algorithms</font>

<ul>

<li> <b>mixed-precision-sylvester</b><br>
Solving the Sylvester matrix equation in mixed precisions via new iterative refinement schemes.   
<a href="https://github.com/north-numerical-computing/mixed-precision-sylvester">Source code</a>.</li>

<li> <b>mhodlr</b><br>
Matrix computations with Hierarchical Off-Diagonal Low-Rank (HODLR) format and mixed precision.   
<a href="https://github.com/chenxinye/mhodlr">Source code</a>.</li>

<li> <b>mpkmeans</b><br>
Mixed-precision k-means clustering algorithm.  
<a href="https://github.com/open-sciml/mpkmeans">Source code</a>.</li>

<li> <b>mp-ps</b><br>
Mixed-precision Paterson--Stockmeyer algorithm for evaluating polynomials of matrices.  
<a href="https://github.com/xiaobo-liu/mp-ps">Source code</a>.</li>

<li> <b>mp-cosm</b><br>
Arbitrary precision algorithms for computing the matrix cosine and its Fréchet derivative. 
<a href="https://github.com/xiaobo-liu/mp-cosm">Source code</a>.</li>

<li> <b>mp-spalg</b><br>
A multiprecision Schur--Parlett algorithm for computing functions of a square matrix without using derivatives of the underlying function.
<a href="https://github.com/xiaobo-liu/mp-spalg">Source code</a>.</li>

</ul>
