My personal website
--------------------

This repository hosts the source files of the [personal GitHub website of Xiaobo Liu](https://xiaobo-liu.github.io/).

The website is based on the [al-folio](https://github.com/alshedivat/al-folio) theme and is built using [Jekyll](https://jekyllrb.com).

Maintenance guide
-----------------

This repository is the source of the public website. Do not edit files inside `_site`; that folder is generated by Jekyll and can be rebuilt at any time.

Useful source locations:

- `_pages/`: main website pages, including `about.md`, `papers.md`, `talks.md`, `teaching.md`, `software.md`, and related pages.
- `_news/`: news announcements shown on the news page.
- `assets/img/`: profile and logo images.
- `assets/pdf/`: PDFs linked from the website.
- `_config.yml`: production site settings.
- `Gemfile.local` and `_config_local.yml`: local preview settings only.

Local preview
-------------

Use local preview before publishing changes. It builds the site on your machine and serves it at <http://127.0.0.1:4000/>.

On this machine, the local Ruby and gems have already been installed. Start the preview server with:

```sh
./scripts/preview
```

The preview server rebuilds the site when files change. If port `4000` is already busy, use another port:

```sh
./scripts/preview --port 4001
```

First-time setup on another machine
-----------------------------------

Install Ruby 3 and Bundler 2.5.7 first. With Homebrew, this is usually:

```sh
brew install ruby
export PATH="$(brew --prefix ruby)/bin:$PATH"
gem install bundler -v 2.5.7
```

Then run:

```sh
./scripts/preview
```

The script installs the local preview gems into `vendor/bundle`, which is ignored by Git.

Editing workflow
----------------

1. Start local preview with `./scripts/preview`.
2. Open <http://127.0.0.1:4000/>.
3. Edit Markdown, images, PDFs, or configuration files.
4. Refresh the browser after the site rebuilds.
5. Check the Git diff before committing.
6. Commit and push to the publishing branch, currently `master`.

Build without serving
---------------------

To test that the local preview build succeeds without starting a server:

```sh
PATH="$PWD/vendor/ruby-3.3.11-local-yaml/bin:$PATH" \
BUNDLE_GEMFILE="$PWD/Gemfile.local" \
bundle _2.5.7_ exec jekyll build --config _config.yml,_config_local.yml
```

Publishing
----------

After changes look correct locally, commit them and push to GitHub. GitHub Pages/GitHub Actions will publish the site from the repository. The local preview files are for editing convenience and do not replace the production configuration.

Troubleshooting
---------------

- `Ruby 3 or newer is required`: install a newer Ruby, then rerun `./scripts/preview`.
- `Bundler 2.5.7 is required`: run `gem install bundler -v 2.5.7`.
- Port already in use: run `./scripts/preview --port 4001`.
- Broken local gems: remove `vendor/bundle` and rerun `./scripts/preview`.
- ImageMagick is intentionally disabled for local preview in `_config_local.yml`; production settings remain in `_config.yml`.
